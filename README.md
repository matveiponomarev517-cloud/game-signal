# Игровой сигнал: автономный канал

Каждый час GitHub Actions запускает `bot.py`. Если в окне 9–23 МСК не исчерпан лимит (5 постов в сутки) и прошла пауза 2 часа, бот публикует следующий формат по кругу: новость → раздача → находка из Steam → «горячее» с Reddit → новость → лонгрид → опрос. Иначе запуск заканчивается за секунды.

**Форматы:** новость (RSS + поиск по интернету, фото из источника), раздача бесплатных игр (GamerPower), находка из Steam (скидки 50%+ = рубрика «Игра за копейки», иногда трейлер до 19 МБ), «горячее» с Reddit (слухи помечаются), лонгрид ответом на анонс, опрос, воскресные итоги недели.

**Дзен:** подключите Telegram-канал в Студии Дзена (Настройки → Кросспостинг → Telegram, бот @zen_sync_bot). Канал должен быть публичным.

## Секреты (Settings → Secrets and variables → Actions → Secrets)
Обязательно: `TG_TOKEN`, `TG_CHAT_ID` (`@канал`), бот админ канала. Нейросеть: `GEMINI_API_KEY` и запасной `GROQ_API_KEY` (оба бесплатные, лучше иметь оба). Рекомендуется `TG_ADMIN_ID` (сбои, тишина 30 ч, недельный отчёт).

## Настройки (там же, вкладка Variables)
`MAX_PER_DAY` 5, `MIN_GAP_MINUTES` 120, `POST_HOUR_FROM`/`POST_HOUR_TO` 9/23, `SOURCE_IMAGE` mix|cover|photo|off, `VIDEO=0`, `WEB_SCOUT=0`, `LONGREADS=0`, `FACTCHECK=0`, `LLM_DAILY_MAX` 60, `GEMINI_MODEL`, `CHANNEL_NAME`. Свой стиль: файл `style.txt` с 3–5 вашими постами.

## Если нейросеть недоступна
Бот не публикует непереведённые английские тексты: берёт форматы, которые работают без неё (раздача, Steam, опрос). Квота Gemini/Groq отслеживается: исчерпанные модели в этот день не опрашиваются, счётчик сбрасывается в 11:00 МСК.

## Проверка
Actions → channel → Run workflow (поле force: `news` / `free` / `gem` / `hot` / `longread` / `poll`). Локально: `python bot.py --check`, `python bot.py --dry-run --force news`, `python test_offline.py`.
